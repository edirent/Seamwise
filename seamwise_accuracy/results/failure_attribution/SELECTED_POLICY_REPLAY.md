# Fixed selected-policy diagnostic replay

After all performance/accuracy jobs finished, the exact frozen selected native configuration was replayed on all 84 original P0 cases. This is exploratory diagnostic evidence, not a new confirmatory cohort or additional parameter selection. All controls and failures remain recorded. Syndrome/frame validity is checked; labels only score already generated corrections.

For each original failed incumbent and radius, the generated correction is clamped to the original exterior. A positive witness requires full syndrome validity, correct full logical frame, and a strictly cheaper conditional cost with a conservative floating allowance. An invalid clamp is not an infeasibility proof. These certificates supplement P0/P1; they do not retrospectively alter the initial audit or prove exact logical-class MAP.
