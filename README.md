This repository contains source, tests, configurations, and selected research reports. The native builds use LDPC headers and GARI sources included under `seamwise_bench/vendor`. Historical datasets, raw run outputs, pinned binary wheels, manuscript figures, and packaged research archives live outside this source checkout. Reproducing the archived runs requires those assets in addition to the code here.
